# 🔐 Login Form UI

A simple and responsive **Login Form** built using **HTML, CSS, and JavaScript**.
This project is perfect for beginners who want to strengthen their frontend fundamentals.

---

## ✨ Features

* 🎨 Clean and modern UI design
* 🌙 Dark / Light mode toggle
* 📱 Fully responsive (mobile-friendly)
* ⚡ Smooth user interactions
* 🔒 Basic form validation (optional JS)

---

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling & Layout
* **JavaScript** – Functionality

---

## 📂 Project Structure

```
login-form/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🌗 Dark Mode Feature

This project includes a **toggle button** that switches between:

* 🌙 Dark Mode
* ☀️ Light Mode

It uses JavaScript to dynamically change the theme.

## 🎯 Learning Outcomes

* Understanding of HTML form structure
* Styling with CSS (colors, layouts, responsiveness)
* DOM manipulation using JavaScript
* Theme toggling logic
